My project is called Quizivia. It is a trivia quiz website where people can answer questions, learn new things, and have fun while testing what they know.

I chose this idea because I wanted to make a website that is simple and enjoyable to use. It is for students and other people who like quizzes and want to learn more about different topics.

The website will have different quiz categories, such as History, Science, Mathematics, and General Knowledge. It will also have a Daily Quiz where users can answer a new set of questions. I also plan to include a leaderboard so users can see the scores and rankings of players.

I want the design to look clean and organized so users can easily find what they are looking for. The colors will use soft lavender and pink tones, with a simple layout and readable text. The buttons and sections should also be easy to understand.

For now, I am working on the basic structure of the website. Some features are only planned and are not working yet. I will improve the design and add more functions as I continue working on the project.

The project folder contains the main HTML file named index.html, a css folder for the website style, and an assets folder where images can be placed. This handoff file explains the idea and the plans for Quizivia.
